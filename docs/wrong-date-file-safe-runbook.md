# แนวทางหน้างานเมื่อส่งไฟล์ผิดวันหรือพบหลังปิดเคส

ใช้เมื่อไฟล์ของบริษัท/วันที่หนึ่งถูกส่งผิดวัน และมีผลกระทบยอดหรือปิดเคสไปแล้ว เช่น MR9 วันที่ 17/11 ก่อนเริ่มรอบวันที่ 18/11

## สิ่งที่ต้องทำ

1. เปิด **ไฟล์และสถานะ → บริษัทและวันที่ที่ส่งผิด → แก้ไฟล์**
2. ระบุเหตุผลให้ชัด แล้วกด **พักรันบริษัท–วันที่นี้**
   - ระบบต้องแสดง `พักบอทแล้ว · คิวเดิมหยุดรอตรวจ`
   - คิวเดิมต้องไม่ค้างเป็น `เข้าคิว` หรือ `กำลังรัน`
   - ผลกระทบยอดที่ยืนยันแล้ว ยอด เคส และประวัติปิดเคสเดิมยังคงอยู่
3. ที่ไฟล์ผิด กด **แก้ข้อมูล / เลือกฉบับแทน** แล้วเลือกอย่างใดอย่างหนึ่ง
   - กักไฟล์ ไม่ให้นำไปกระทบยอด
   - แก้บริษัท/วันอ้างอิงเป็นเวอร์ชันใหม่
   - อัปโหลดฉบับที่ถูกต้อง โดยเก็บต้นฉบับเดิมไว้
4. เลือกเฉพาะไฟล์ที่ถูกต้อง แล้วกด **ทบทวนรันมือ**
   - ผลรันมือเป็นรายงานเปรียบเทียบ
   - ยังไม่แทนผลหลัก ไม่สร้างเคสเพิ่ม และไม่ปิดหรือเปิดเคสเดิม
5. หัวหน้า/Admin ตรวจผลเดิมกับผลแก้ไข โดยเฉพาะเคสที่ปิดแล้วและคู่รายการข้ามวัน
6. ยืนยันผลใหม่เฉพาะเมื่อหลักฐานและชุดเคสถูกต้องครบ หากไม่ครบให้คงผลเดิมและพักรอบต่อ
7. ตรวจไฟล์วันที่ 18/11 แยกจากวันที่ 17/11 แล้วจึงให้รอบ 18/11 ทำงานตามปกติ ไม่ต้องเปิดคิววันที่ผิดกลับมาเพื่อให้ปิดข้ามวัน

## สิ่งที่ห้ามทำ

- ห้ามลบไฟล์ต้นฉบับหรือแก้ยอดในผลรันเดิม
- ห้ามกดรันซ้ำอัตโนมัติทั้งบริษัทเพื่อแก้ไฟล์เพียงฉบับเดียว
- ห้ามบังคับปิดเคสข้ามวันโดยไม่มีคู่รายการและหลักฐานล่าสุด
- ห้ามเปิดรอบที่พักจนกว่าหัวหน้า/Admin จะตรวจผลมือและความเชื่อมโยงเคสเดิมครบ

## เมื่อสถานะไม่ถูกต้อง

- พักแล้วแต่ยังเห็น `เข้าคิว`: กดโหลดสถานะล่าสุด หากยังไม่เปลี่ยนเป็น `รอตรวจ` ให้แจ้ง IT พร้อมบริษัท วันที่ และเหตุผลพัก
- รอบวันถัดไปปิดข้ามวันไม่ได้: ตรวจว่ารอบวันที่ผิดไม่มี `queued/running` ค้าง และผลวันถัดไปผ่านการยืนยันแล้ว
- ผลเดิมหรือเคสที่ปิดแล้วเปลี่ยน: หยุดดำเนินการทันที ห้ามยืนยันผลใหม่ และส่ง Audit Log ให้ IT ตรวจ
