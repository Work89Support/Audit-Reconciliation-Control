# ตัวอ่านภาพ TMN ที่มีคำสั่งจัดวาง PDF ซ้อนกัน

ตัวอ่านตรวจ graphics state (`q/Q`), ผลคูณเมทริกซ์ และ clipping ของภาพก่อนแยกแถว รองรับภาพที่ถูกกลับแกนซ้อนกันแล้วแสดงตั้งตรงจริง โดยไม่ทิ้งข้อความ รูปซ้อน สี/ความโปร่งใส หรือส่วนที่ PDF บังไว้ รูปแบบที่ยังพิสูจน์ไม่ได้ต้องพักตรวจ ตัวครอปเวลาเก็บถึงขอบภาพจริง ไม่กันท้ายภาพตามสัดส่วนตายตัว

เมื่อชุดภาพเรียงหน้าจากช่วงเวลาเก่าไปใหม่และหัววันที่อยู่หน้าสุดท้าย จะใช้วันที่นั้นได้เฉพาะเมื่อมีหัววันที่แบบเต็มเพียงหัวเดียว อยู่ก่อนรายการในหน้านั้น ทุกหน้ามีหลักฐานภาพและแถวครบ เวลาในแต่ละหน้าเรียงลง และช่วงเวลาระหว่างหน้าไม่ทับกัน เก็บเลขหน้าต้นฉบับและอ้างอิงหน้า/แฮชของหัววันที่ทุกแถว ไม่ใช้วันที่จาก BO ชื่อไฟล์ หรือนาฬิกาโทรศัพท์ กรณีอื่นยังใช้กฎหัววันที่ก่อนรายการตามเดิม หรือพักตรวจเมื่อยืนยันไม่ได้

คงทุกแถวจริงแม้ชื่อ เวลา หรือยอดซ้ำ ค่าธรรมเนียมเก็บใน page audit และแยกออกจากยอดกระทบยอด หากแยกหน้าไม่สำเร็จ ส่ง error receipt กลับ Quality Gate เดิมเพื่อพักตรวจ แทนการปล่อย execution หยุดแล้วค้างสถานะ running ทาง error ไม่ข้ามไปสร้างผลหลักหรือเคส

ใช้ `scripts/sync-worker-tmn-reader.mjs INPUT.json OUTPUT.json` กับ export Production ล่าสุดที่สำรองไว้แยก ตัว patch อัปเดตเฉพาะ splitter, TMN modules ใน normalizer, formatter และทางรับข้อผิดพลาดของ TMN คง workflow ID, credentials, settings, schedules, กฎจับคู่ และจุดบันทึกผลเดิม การสร้าง candidate ไม่ใช่การ Publish

ก่อนอัปโหลดให้ทดสอบไฟล์จริงแยกครบทุกหน้าและตรวจ field-to-source จากต้นฉบับ จากนั้นตรวจว่าไม่มี execution/running job อยู่ จึง Publish ออโต้และรันมือด้วย reader รุ่นเดียวกัน ตรวจ job/run/source files หลังรัน พร้อมเทียบ hash ของผลเดิม เคสที่ปิดแล้ว และหลักฐานเดิม ห้ามเก็บไฟล์จริง workflow export หรือ account mapping ส่วนตัวใน repo สาธารณะ
