# การอ่าน statement BAY แบบแยกคอลัมน์

ตัวอ่านเดียวกันรองรับแถววันที่/เวลาแยกบรรทัด และคอลัมน์ถอน ฝาก ยอดเงินในบัญชี รหัส TN/TW รายละเอียด ช่องทาง และรหัสสาขา โดยเก็บข้อความต้นฉบับและตำแหน่งแถวไว้ ไม่ใช้รหัสสาขาเป็นยอด ไม่ยุบรายการที่ชื่อ เวลา หรือยอดซ้ำ และไม่เปลี่ยนวันที่ต้นฉบับ

ก่อนนำไปกระทบยอดต้องตรวจเวลา จำนวนเงิน ทิศทางจากรหัสและรายละเอียด ตำแหน่งคอลัมน์เมื่อมีพิกัด และความต่อเนื่องของยอดคงเหลือข้ามหน้า ข้อมูลที่ขาดหรือขัดแย้งยังไม่ผ่าน Quality Gate รูปแบบ BAY เดิมใช้ตัวอ่านเดิม

ไฟล์ที่ไม่มีหัวเลขบัญชีต้องมีทะเบียนเจ้าของที่ตรวจเทียบ BO และหัว statement ที่เชื่อถือได้แล้ว เก็บทะเบียนจริงเฉพาะตัวแปร n8n ส่วนตัว `AUDIT_BAY_STATEMENT_OWNERS_JSON` เป็นอาร์เรย์ของ `company`, `account`, `holder`, `aliases` และ `sourceRef` ทั้ง probe และ normalizer อ่านตัวแปรเดียวกัน กรองบริษัทตามงานและเทียบชื่อเจ้าของในชื่อไฟล์ตรงกับ alias เท่านั้น ถ้าไม่พบ พบหลายบัญชี หรือบัญชีบนหัวขัดกัน ต้องพักตรวจ ห้ามนำบัญชีคู่โอนมาแทนเจ้าของ

ค่าบัญชีจริง ไฟล์จริง และ workflow export จาก Production ต้องไม่เผยแพร่ลง repo ใช้ข้อมูลสังเคราะห์ใน `tests/bay-column-statement.test.mjs` ส่วนไฟล์จริงและผลตรวจ wrapper เก็บแยกในพื้นที่ส่วนตัว การอัปเดตตัวอ่านนี้ไม่แก้กฎจับคู่ ตัวปิดเคส ตารางผลหลัก หรือประวัติหลักฐาน
