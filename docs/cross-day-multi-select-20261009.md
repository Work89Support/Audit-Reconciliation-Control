# Multi-select BO and STM

BO select-all is scoped to the visible company/account/date/23:00-23:59 cases. STM select-all selects only verified, unreserved rows in the current scoped document. Checkboxes retain separate selected rows; explicit single-pair preparation is still available.

Batch preparation only assigns reciprocal unique candidates with the existing company, account, actual date, direction and <=5 THB constraints. It never zips by display order or guesses duplicate amounts. Ambiguous cases remain selected and require explicit pairing. Prepared pairs use the existing batch submission/head closure RPCs. This does not change database approval or source-quality rules.
