# Audit AI Reconciliation

Prototype เว็บสำหรับระบบ Audit ที่สรุปจาก MOM วันที่ 1/8/2026 โดยเน้นงานตรวจสอบรายการเงินจำนวนมาก, 3-point match, queue รายการผิดปกติ, workflow ชี้แจง/อนุมัติ, ทะเบียนความเสียหาย, Talk to Data, KPI ตามกะ และสิทธิ์ตามบทบาท

ตอนนี้เป็น **Single Page Application** แบบไม่มี build step ที่ทำงานครบทั้ง 4 เฟสของ roadmap ในฝั่งเบราว์เซอร์: อ่านไฟล์ CSV/Excel จริง, ใช้กฎธนาคารกรองข้อมูล, จับคู่ 3 จุดแบบคำนวณสด, workflow ชี้แจง/อนุมัติ/ความเสียหาย, dashboard และ Talk to Data, ไปจนถึงการแจ้งเตือน ตั้งเวลารันอัตโนมัติ และทดสอบ performance ระดับ 200,000 รายการ

## ฟังก์ชันที่ทำงานได้จริง

**Phase 1 — MVP Reconciliation**

- ดึงไฟล์จากกล่องอีเมลกลาง (จำลอง) หรือลากไฟล์ของคุณเองมาวาง รองรับ `.csv` และ `.xlsx`
- Parser ตรวจหัวคอลัมน์เองว่าไฟล์เป็น STM ธนาคารไหน, รายงาน BO หรือ STM PM
- Bank rule engine กรองบรรทัดยอดยกมา, บรรทัดรอบวันที่, แปลง marker X1/X2/XB, แยก Transfer SAV Deposit / MyMo SAV Withdraw, คัดเฉพาะรายการ PM ที่สำเร็จ และตัดวันที่ที่ไม่ตรงกับวันที่ตรวจ
- จับคู่ 3 จุด (account + time + amount) แบบคำนวณสดพร้อมแถบความคืบหน้า และยกเป็น exception ตาม taxonomy จริง
- **ไม่มีปุ่มสั่งกระทบยอด** — ระบบทำงานเองเมื่อไฟล์เข้าครบทั้งฝั่งธนาคารและฝั่ง BO, เมื่อมีไฟล์เพิ่มเข้ามา, เมื่อเปลี่ยนกฎธนาคารหรือ tolerance (อ่านไฟล์เดิมใหม่ให้ด้วย) และเมื่อถึงเวลาตามตารางที่ตั้งไว้ · สถานะการทำงานอัตโนมัติแสดงที่มุมบนขวาตลอดเวลา
- ตารางตรวจความถูกต้องของ engine — เทียบสิ่งที่ระบบตรวจพบกับข้อบกพร่องที่จงใจใส่ไว้ในไฟล์ตัวอย่าง

**Phase 2 — PM & Damage Workflow**

- บัญชี PM ทั้ง 3 บริษัทเข้าสู่การจับคู่เดียวกัน พร้อมกฎเฉพาะของ PM
- ส่งชี้แจง → ตอบชี้แจง → แนบไฟล์หลักฐานจริง (เปิดดูได้) → บันทึกเป็นความเสียหาย → อนุมัติปิดเคส
- ทะเบียนความเสียหายแยกรอบ 1-15 / 16-25 / 26-สิ้นเดือน ปิดรอบแล้วล็อก

**Phase 3 — Analytics & Talk to Data**

- Dashboard, KPI ตามกะ/พนักงาน/บริษัท, trend 12 เดือน
- Talk to Data ตอบจากข้อมูลจริงในระบบ พร้อมลิงก์กลับไปหน้าที่กรองไว้แล้ว

**Phase 4 — Automation & Hardening**

- ศูนย์แจ้งเตือนพร้อมกฎ (ไฟล์ขาด, Critical, เลย SLA, ใกล้ครบรอบ) และช่องทางที่เลือกได้
- ตั้งเวลาให้ระบบดึงไฟล์จากอีเมลกลางแล้วกระทบยอดเอง พร้อมแสดงรอบถัดไป
- นโยบายเก็บข้อมูล 12 เดือน, สำรองรายวัน, เข้ารหัส, ปิดบังเลขบัญชี
- ทดสอบ performance 50k / 100k / 200k รายการ วัดเวลาและอัตราการจับคู่จริง
- บันทึกสถานะเคส, การแจ้งเตือน, audit log และการตั้งค่า ข้ามการรีเฟรชหน้า

**ทั่วทั้งระบบ**

- ตัวกรองหลัก (วันที่ตรวจ / ช่วงข้อมูล / วันเริ่มต้น-สิ้นสุด / บริษัท / ประเภทบัญชี / กะ) มีผลกับทุกหน้าที่เกี่ยวข้อง รวมถึงไฟล์ที่ export
- ค้นหา กรองตามประเภท / ระดับ / สถานะ / เฉพาะที่เลย SLA, เรียงตามคอลัมน์, แบ่งหน้า
- เปิดรายละเอียดเคส: ดู raw STM / BO, ใส่ note (ลบไม่ได้), ส่งชี้แจง, ตอบชี้แจง, บันทึกเป็นความเสียหาย, อนุมัติปิดเคส
- Close checklist บังคับก่อนปิดเคส และกฎบังคับแนบหลักฐาน
- ปิดรอบความเสียหายแล้วล็อกรอบ
- สลับมุมมองสิทธิ์ 5 บทบาท — เมนูและปุ่มเปลี่ยนตามสิทธิ์จริง
- Export เป็นไฟล์ **Excel (.xlsx) จริง** เลือกได้ว่าจะเอาชุดข้อมูลไหนบ้าง แต่ละชุดเป็นคนละชีตในไฟล์เดียว
- ทุก action สำคัญถูกบันทึกลง Audit Log อัตโนมัติ
- Talk to Data ตอบจากข้อมูลจริงในชุดข้อมูล พร้อมลิงก์ไปหน้าที่กรองไว้ให้แล้ว

## คู่มือการใช้งานในระบบ

มีปุ่มกลม **“คู่มือ”** ลอยอยู่มุมขวาล่างของทุกหน้า กดเพื่อเปิดคู่มือ

- เป็น**หน้าต่างลอย** ไม่บังการทำงาน — เปิดคู่มือค้างไว้แล้วกดใช้งานระบบไปพร้อมกันได้
- **สารบัญด้านซ้าย** 23 หัวข้อ กดแล้วเลื่อนไปหัวข้อนั้น และไฮไลต์ตามหัวข้อที่กำลังอ่านอยู่
- มี**ช่องค้นหา**หัวข้อ
- ทุกหัวข้อมี**ภาพหน้าจอจริง**ของระบบ คลิกที่ภาพเพื่อดูขนาดใหญ่
- **ลากหัวหน้าต่าง**เพื่อย้าย และ**ลากมุมขวาล่าง**เพื่อปรับขนาด
- กด **—** เพื่อย่อกลับเป็นปุ่มกลม ซึ่ง**ลากไปวางตรงไหนก็ได้** และระบบจำตำแหน่งไว้ให้แม้ปิดเปิดใหม่
- กด **F1** เพื่อเปิด/ปิดคู่มือได้เช่นกัน

## การ Export

**Excel (.xlsx)**

กดปุ่ม **Export** มุมบนขวา จะเปิดหน้าต่างให้เลือก

- ช่วงวันที่ — มี preset (วันที่ตรวจ / 7 วัน / 30 วัน / เดือนนี้ / เดือนก่อน / ไตรมาสนี้ / ปีนี้) หรือกรอกวันเริ่มต้น-สิ้นสุดเอง
- ชุดข้อมูล — รายการผิดปกติ, ทะเบียนความเสียหาย, KPI รายพนักงาน, สรุปรายชั่วโมง, แนวโน้มรายเดือน, สถานะไฟล์ที่รับ, Audit Log (แต่ละชุด = 1 ชีต และบอกจำนวนแถวให้เห็นก่อนกด)
- รูปแบบ — Excel หรือ CSV

ไฟล์ Excel ที่ได้จะมี **หัวตารางตัวหนาพื้นสีน้ำเงิน, ตรึงหัวตาราง, autofilter ทุกคอลัมน์, ความกว้างคอลัมน์ที่ตั้งไว้แล้ว และตัวเลขเป็นตัวเลขจริงที่ SUM ได้ทันที** พร้อมบรรทัดกำกับว่าเป็นข้อมูลช่วงไหน ใครออก และออกเมื่อไหร่

ตัวสร้างไฟล์ Excel เขียนไว้ในโปรเจกต์เอง (`xlsx-writer.js`) จึงใช้งานได้แม้เครื่องไม่ต่ออินเทอร์เน็ต

หน้าที่มีปุ่ม Export เฉพาะทาง (ความเสียหาย, KPI, Audit Log, รายงานรายวัน/รายเดือน) จะออกไฟล์ Excel ตามช่วงวันที่ที่เลือกอยู่เช่นกัน

**บันทึกเป็นภาพ (PNG)**

- ทุกการ์ดในทุกหน้ามี **ปุ่มกล้อง** ที่มุมขวาบน (ปรากฏเมื่อเอาเมาส์ชี้) กดเพื่อบันทึกเฉพาะส่วนนั้นเป็นภาพ เหมาะกับการแปะในไลน์ อีเมล หรือสไลด์
- หน้ารายงานมีปุ่ม **บันทึกทั้งหน้าเป็นภาพ** ซึ่งจะรวมทุกการ์ดเป็นภาพเดียวพร้อมหัวเรื่องและช่วงวันที่
- ทำงานได้แม้ไม่มีอินเทอร์เน็ต (มีตัวจับภาพในตัว) ถ้าต่อเน็ตได้จะใช้ html2canvas ซึ่งให้ผลตรงกับหน้าจอมากกว่า

## วิธีลองใช้แบบเต็ม

1. เปิด `index.html`
2. ไปหน้า **นำเข้าข้อมูล** → กด **ดึงไฟล์ทั้งหมด** (หรือกด "ดาวน์โหลด" ที่ไฟล์ใดไฟล์หนึ่งไปเปิดดูก่อนก็ได้)
3. ระบบจะ parse, ใช้กฎธนาคาร แล้วกระทบยอดให้เองทันที (ดูสถานะที่ชิป "อัตโนมัติ" มุมบนขวา)
4. ดูตาราง **Engine Validation** ท้ายหน้าเพื่อเทียบว่าระบบตรวจเจอตรงกับข้อบกพร่องที่ใส่ไว้ในไฟล์หรือไม่
5. ไป **แดชบอร์ด** และ **รายการผิดปกติ** — ตัวเลขทั้งหมดมาจากไฟล์ที่เพิ่งนำเข้า
6. เปิดเคสสักเคส → แนบหลักฐาน → ใส่ note → ส่งชี้แจง → อนุมัติปิดเคส
7. กดปุ่มกลม **คู่มือ** มุมขวาล่างเพื่ออ่านวิธีใช้แต่ละหน้า พร้อมภาพประกอบ
8. ลองไป **ตั้งค่าระบบ** เปลี่ยน tolerance แล้วกดบันทึก — ระบบจะอ่านไฟล์เดิมใหม่และกระทบยอดใหม่ให้เอง
9. ไป **ตั้งเวลา & ความปลอดภัย** → กด **เริ่มทดสอบ** performance ที่ 200,000 รายการ

## ข้อจำกัดที่ต้องรู้

- ทุกอย่างทำงานในเบราว์เซอร์ ยังไม่มี backend และฐานข้อมูล — ข้อมูลที่นำเข้าจะหายเมื่อรีเฟรช (สถานะเคส การแจ้งเตือน และการตั้งค่าถูกเก็บไว้)
- กล่องอีเมลกลางเป็นการจำลอง ยังไม่ได้ต่อ IMAP จริง
- ตัวตั้งเวลาทำงานขณะเปิดหน้าเว็บไว้เท่านั้น ในระบบจริงต้องเป็น cron หรือ job queue ฝั่ง server
- Talk to Data ใช้การจับคำสำคัญบนข้อมูลในระบบ ยังไม่ใช่ LLM หรือ SQL generation
- การ **อ่าน** ไฟล์ `.xlsx` ที่อัปโหลดเข้ามา ต้องต่ออินเทอร์เน็ตครั้งแรกเพื่อโหลดตัวอ่าน (ไฟล์ `.csv` ใช้ได้แบบออฟไลน์) ส่วนการ **เขียน** ไฟล์ Excel ใช้ได้ออฟไลน์เสมอ
- ไฟล์ตัวอย่างเป็นข้อมูลสมมติทั้งหมด ห้ามนำข้อมูลจริงของธนาคารหรือลูกค้าขึ้น GitHub Pages
